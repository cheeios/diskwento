Overview

What's New

Version 1.1.0 is a major update that expands Diskwento beyond the core discount checker. This release introduces document storage, transaction history, a standalone VAT calculator, full accessibility support for users with disabilities, and official Android support.

Upgrading from v1.0.0? When you open the app for the first time after updating, a short What's New walkthrough will highlight the three biggest additions.

New Features

What's Been Added

🧮

VAT Calculator

A standalone tool for understanding how much 12% VAT is embedded in any price. See the base price, the tax amount, and compare with VAT rates from over 20 countries around the world.

  • Instant 12% VAT breakdown: base price, tax amount, VAT-inclusive total
  • Random "VAT Around the World" comparison — 20+ countries
  • Special historical note: the Philippines' VAT before RA 9337 raised it to 12% in 2006
  • Save calculations to transaction history with a custom label
📋

Reseta Vault

Store your prescriptions and receipts as photos, privately on your device. No cloud, no account, no internet required.

  • Take a photo or choose from your library
  • Full-screen viewer with pinch-to-zoom and pan
  • Double-tap to reset zoom
  • Stored in app's private directory — not accessible to other apps
  • Long-press thumbnail or use the trash icon in viewer to delete
🪪

Discount ID Storage

Keep a digital copy of your PWD ID and Senior Citizen ID inside the app, accessible offline at any time.

  • Separate sections for PWD ID and Senior Citizen ID
  • Full-screen viewer with pinch-to-zoom and pan
  • Stored privately on-device
🕐

Transaction History

Every discount check and VAT calculation you save is stored in one place, organized by date.

  • Shows discount transactions and VAT calculations in a unified timeline
  • Status pill per transaction: Correct, Overcharged, or Reported
  • Swipe left to delete individual entries
  • Clear All option for bulk deletion
📖

Onboarding & About Screen

New users are welcomed with a 4-slide introduction explaining the app's purpose, the correct workflow, and key features.

  • 4 slides: Welcome, After Your Receipt, Compare & Report, Know Your Taxes
  • Skip or tap through; preference saved — never shown again after completion
  • About screen with version info, developer contact, and legal links

Accessibility

Built for Everyone

v1.1.0 includes a comprehensive accessibility pass across every screen, making Diskwento fully usable for people who rely on screen readers or other assistive technologies.

VoiceOver (iOS)

All screens fully labeled. Buttons, rows, modals, and dynamic state changes are all announced correctly.

TalkBack (Android)

Full TalkBack support across all screens. Swipeable list rows include an Actions rotor entry for delete.

Reduce Motion

All animations (home card press, VAT fade-in, onboarding dots, image viewer spring) are disabled when Reduce Motion is on.

Dynamic Type & Font Scaling

Text scales correctly with iOS Dynamic Type and Android font size settings. Caps raised to 1.4×–1.5× on key elements.

Modal Accessibility

All modals set accessibilityViewIsModal so VoiceOver focus is trapped inside while they are open.

Semantic Roles

Headers, buttons, and links are correctly marked. Decorative elements are hidden from the accessibility tree.

Platform

Android Support

Diskwento is now available on Android. Several platform-specific fixes were required:

Save Transaction modal — Android does not support Alert.prompt. A native-styled modal with a text input is shown instead.

Image viewer zoom — Android's Modal creates a new native window outside the gesture handler root. Fixed by wrapping each viewer with its own GestureHandlerRootView.

Gesture responsiveness — Double-tap detection lag reduced from 500 ms to 200 ms. All gesture callbacks explicitly run on the UI thread via the 'worklet' directive. Pan uses averageTouches for smooth multi-finger tracking.

Font size accessibility — maxFontSizeMultiplier caps raised across all screens so Android's "Largest" font size setting is properly respected.

Legal Basis

Statutory Foundation

RA 9994

Expanded Senior Citizens Act of 2010 — Grants senior citizens (60+) a 20% discount and VAT exemption on covered goods and services.

RA 7277

Magna Carta for Persons with Disability — As amended by RA 9442 and RA 10754, grants PWD cardholders a 20% discount and VAT exemption on covered establishments.

RA 9337

Reformed VAT (RVAT) Law — Raised the Philippine VAT rate from 10% to 12% effective February 1, 2006. Referenced in the VAT Calculator's historical comparison feature.
